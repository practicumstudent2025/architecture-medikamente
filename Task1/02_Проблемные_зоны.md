# Список проблемных зон системы безопасности «Медикаменте»

## 1. Проблемы хранения данных

- **Отсутствие шифрования** (Критично): Все данные в открытом виде
- **Централизованное хранение без разграничения** (Критично): Общий доступ для всех сотрудников
- **Отсутствие резервного копирования** (Высокая): Риск потери данных

## 2. Проблемы контроля доступа

- **Недостаточная аутентификация** (Высокая): Только доменная, нет MFA
- **Отсутствие RBAC/ABAC** (Критично): Нет ролевой модели доступа
- **Нет принципа минимальных привилегий** (Высокая): Избыточный доступ

## 3. Проблемы обработки данных

- **Ручная обработка** (Средняя): Ошибки, случайное удаление
- **Двойной учёт** (Средняя): Расхождения в данных
- **Отсутствие валидации** (Средняя): Некорректные данные

## 4. Проблемы передачи данных

- **Небезопасные каналы** (Высокая): Передача без шифрования
- **Интеграция с лабораторией** (Критично): Нет контролируемого API
- **Отсутствие контроля передачи** (Высокая): Нет логирования

## 5. Проблемы аудита и мониторинга

- **Отсутствие аудита доступа** (Критично): Нет логирования доступа
- **Отсутствие мониторинга** (Высокая): Нет обнаружения аномалий
- **Нет алертинга** (Высокая): Отсутствие уведомлений

## 6. Проблемы соответствия требованиям

- **Несоответствие 152-ФЗ** (Критично): Нарушение законодательства
- **Отсутствие Privacy By Design** (Высокая): Защита не заложена в архитектуру
- **Нарушение Data Minimization** (Средняя): Избыточные данные
- **Отсутствие Data Lineage** (Высокая): Невозможно отследить данные

## 7. Проблемы масштабируемости

- **Файловый режим 1С** (Средняя): Не поддерживает масштабирование
- **Локальный сервер** (Средняя): Риск физического доступа

## 8. Проблемы управления жизненным циклом

- **Отсутствие политик хранения** (Средняя): Нет сроков хранения
- **Отсутствие механизма удаления** (Высокая): Нарушение прав пациентов
- **Нет учёта согласий** (Критично): Обработка без согласия

## 9. Приоритизация

### Критические (немедленно):
1. Отсутствие RBAC/ABAC
2. Централизованное хранение без разграничения
3. Отсутствие аудита доступа
4. Интеграция с лабораторией без контроля
5. Несоответствие 152-ФЗ
6. Нет учёта согласий

### Высокие (1-2 месяца):
1. Отсутствие шифрования
2. Недостаточная аутентификация
3. Небезопасные каналы передачи
4. Отсутствие мониторинга
5. Отсутствие механизма удаления

### Средние (при планировании):
1. Ручная обработка данных
2. Двойной учёт
3. Файловый режим 1С
4. Отсутствие политик хранения
