# Список инструментов, способов и мер для обеспечения конфиденциальности данных

## 1. Шифрование данных

### 1.1. Шифрование на уровне хранения (Encryption at Rest)

#### Инструменты:
- **AWS KMS (Key Management Service)** - управление ключами шифрования
- **Azure Key Vault** - централизованное хранилище ключей
- **HashiCorp Vault** - управление секретами и ключами
- **Google Cloud KMS** - управление ключами в GCP
- **BitLocker** (для Windows Server) - шифрование дисков
- **LUKS** (для Linux) - шифрование дисков

#### Применение:
- Шифрование баз данных (PostgreSQL, MySQL с прозрачным шифрованием)
- Шифрование файловых хранилищ (S3 с SSE, Azure Blob Storage)
- Шифрование бэкапов

### 1.2. Шифрование при передаче (Encryption in Transit)

#### Инструменты:
- **TLS 1.3** - протокол шифрования для HTTP/HTTPS
- **mTLS (Mutual TLS)** - взаимная аутентификация для API
- **VPN** - защищённые туннели для удалённого доступа
- **IPSec** - шифрование на сетевом уровне

#### Применение:
- Все API-вызовы через HTTPS
- Интеграция с лабораторией через mTLS
- Удалённый доступ через VPN

## 2. Контроль доступа

### 2.1. Аутентификация

#### Инструменты:
- **Active Directory** (уже используется) - базовая аутентификация
- **Azure AD / Entra ID** - облачная аутентификация
- **Okta** - Identity Provider
- **Keycloak** - open-source Identity Provider
- **MFA (Multi-Factor Authentication)** - двухфакторная аутентификация
  - **Microsoft Authenticator**
  - **Google Authenticator**
  - **YubiKey** - аппаратные ключи

#### Применение:
- MFA для всех сотрудников с доступом к конфиденциальным данным
- SSO (Single Sign-On) для упрощения доступа

### 2.2. Авторизация (RBAC/ABAC)

#### Инструменты:
- **RBAC (Role-Based Access Control)**
  - Встроенные роли в базах данных
  - Кастомные системы на базе OAuth 2.0 / OIDC
- **ABAC (Attribute-Based Access Control)**
  - **Open Policy Agent (OPA)** - политики на основе атрибутов
  - **AWS IAM Policies** - политики доступа
  - **Azure RBAC** - ролевой доступ в Azure

#### Применение:
- Роли: Doctor, Reception, Cashier, Accountant, Admin
- Политики на основе тегов данных
- Динамический контроль доступа

### 2.3. Принцип минимальных привилегий

#### Инструменты:
- **Just-In-Time (JIT) Access** - временный доступ по запросу
- **Privileged Access Management (PAM)**
  - **CyberArk** - управление привилегированным доступом
  - **BeyondTrust** - PAM решение
- **Secrets Management**
  - **HashiCorp Vault**
  - **AWS Secrets Manager**

## 3. Мониторинг и аудит

### 3.1. Логирование доступа

#### Инструменты:
- **ELK Stack (Elasticsearch, Logstash, Kibana)** - централизованное логирование
- **Splunk** - платформа для анализа логов
- **AWS CloudTrail** - аудит действий в AWS
- **Azure Monitor** - мониторинг и логирование
- **Grafana Loki** - агрегация логов
- **Prometheus + Grafana** - метрики и визуализация

#### Применение:
- Логирование всех обращений к конфиденциальным данным
- Аудит изменений в медицинских картах
- Трекинг передачи данных

### 3.2. Обнаружение аномалий

#### Инструменты:
- **SIEM (Security Information and Event Management)**
  - **Splunk Enterprise Security**
  - **IBM QRadar**
  - **ArcSight**
- **UEBA (User and Entity Behavior Analytics)**
  - **Exabeam**
  - **Varonis**
- **Machine Learning для обнаружения аномалий**
  - **AWS GuardDuty**
  - **Azure Sentinel**

#### Применение:
- Обнаружение нетипичных паттернов доступа
- Алерты при массовом экспорте данных
- Выявление подозрительной активности

### 3.3. Data Loss Prevention (DLP)

#### Инструменты:
- **Microsoft Purview Data Loss Prevention**
- **Symantec DLP**
- **Forcepoint DLP**
- **McAfee DLP**
- **AWS Macie** - обнаружение чувствительных данных в S3

#### Применение:
- Сканирование передаваемых данных через API
- Блокировка несанкционированной передачи
- Мониторинг email и файловых обменов

## 4. Управление данными

### 4.1. Data Classification и Tagging

#### Инструменты:
- **Microsoft Purview Information Protection**
- **AWS Data Classification**
- **Apache Atlas** (для Data Lake)
- **Collibra** - управление данными
- **Alation** - каталог данных

#### Применение:
- Автоматическое тегирование данных
- Применение политик на основе тегов

### 4.2. Data Lineage

#### Инструменты:
- **Apache Atlas** - отслеживание происхождения данных
- **Collibra Data Lineage**
- **Alation Data Lineage**
- **Informatica Data Lineage**

#### Применение:
- Отслеживание перемещения данных
- Аудит источников данных
- Соответствие требованиям

### 4.3. Data Minimization

#### Инструменты:
- **Data Retention Policies** - автоматические политики удаления
- **Data Anonymization Tools**
  - **ARX** - open-source инструмент обезличивания
  - **Microsoft Presidio** - обнаружение и обезличивание PII
- **Pseudonymization Tools**

#### Применение:
- Автоматическое удаление данных по истечении срока
- Обезличивание для аналитики
- Минимизация собираемых данных

#### Применение:
- Защита API интеграции с лабораторией
- Контроль доступа к API
- Валидация входных данных

## 10. План внедрения

### Фаза 1 (0-3 месяца):
1. Внедрение шифрования (Vault, PostgreSQL encryption)
2. Настройка логирования (ELK Stack)
3. Базовый RBAC
4. Тегирование данных (Apache Atlas)

### Фаза 2 (3-6 месяцев):
1. MFA для всех сотрудников
2. API Gateway с mTLS
3. DLP для внешних интеграций
4. Мониторинг и алертинг

### Фаза 3 (6-12 месяцев):
1. Полный ABAC
2. SIEM с ML-обнаружением аномалий
3. Автоматизация compliance
4. Data Lineage для всех потоков
