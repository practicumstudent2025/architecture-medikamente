# Инструменты и меры для обеспечения конфиденциальности данных

## 1. Шифрование

### Encryption at Rest:
- **Инструменты**: AWS KMS, Azure Key Vault, HashiCorp Vault, Google Cloud KMS, BitLocker, LUKS
- **Применение**: Базы данных, файловые хранилища, бэкапы

### Encryption in Transit:
- **Инструменты**: TLS 1.3, mTLS, VPN, IPSec
- **Применение**: API-вызовы, интеграция с лабораторией, удалённый доступ

## 2. Контроль доступа

### Аутентификация:
- **Инструменты**: Active Directory, Azure AD, Okta, Keycloak, MFA (Microsoft/Google Authenticator, YubiKey)
- **Применение**: MFA для всех сотрудников, SSO

### Авторизация (RBAC/ABAC):
- **Инструменты**: OAuth 2.0/OIDC, Open Policy Agent (OPA), AWS IAM, Azure RBAC
- **Применение**: Роли (Doctor, Reception, Cashier, Accountant, Admin), политики на основе тегов

### Принцип минимальных привилегий:
- **Инструменты**: JIT Access, PAM (CyberArk, BeyondTrust), Secrets Management (Vault, AWS Secrets Manager)

## 3. Мониторинг и аудит

### Логирование:
- **Инструменты**: ELK Stack, Splunk, AWS CloudTrail, Azure Monitor, Grafana Loki, Prometheus + Grafana
- **Применение**: Логирование доступа к данным, аудит изменений, трекинг передачи

### Обнаружение аномалий:
- **Инструменты**: SIEM (Splunk, IBM QRadar, ArcSight), UEBA (Exabeam, Varonis), ML (AWS GuardDuty, Azure Sentinel)
- **Применение**: Обнаружение нетипичных паттернов, алерты при массовом экспорте

### DLP:
- **Инструменты**: Microsoft Purview DLP, Symantec DLP, Forcepoint DLP, McAfee DLP, AWS Macie
- **Применение**: Сканирование передаваемых данных, блокировка утечек

## 4. Управление данными

### Data Classification и Tagging:
- **Инструменты**: Microsoft Purview, AWS Data Classification, Apache Atlas, Collibra, Alation
- **Применение**: Автоматическое тегирование, применение политик

### Data Lineage:
- **Инструменты**: Apache Atlas, Collibra, Alation, Informatica
- **Применение**: Отслеживание перемещения данных, аудит источников

### Data Minimization:
- **Инструменты**: Data Retention Policies, ARX, Microsoft Presidio
- **Применение**: Автоматическое удаление, обезличивание для аналитики

## 5. Безопасность API

### API Gateway:
- **Инструменты**: Kong, AWS API Gateway, Azure API Management, Apigee, Traefik
- **Применение**: Централизованное управление, rate limiting, аутентификация, логирование

### API Security:
- **Инструменты**: OAuth 2.0/OIDC, JWT, API Keys, mTLS
- **Применение**: Защита интеграции с лабораторией, контроль доступа

## 6. Резервное копирование

- **Инструменты**: Veeam, Commvault, AWS Backup, Azure Backup, BorgBackup
- **Применение**: Ежедневное копирование, шифрование, тестирование восстановления

## 7. Соответствие требованиям

### Compliance:
- **Инструменты**: Vanta, Drata, OneTrust, TrustArc
- **Применение**: Соответствие 152-ФЗ, управление согласиями, отчёты

### Privacy Management:
- **Инструменты**: OneTrust, BigID, Securiti.ai
- **Применение**: Управление согласиями, обработка запросов на удаление

## 8. Сетевая безопасность

- **Network Segmentation**: Firewalls, NAC, SDN, Zero Trust
- **IDS/IPS**: Snort, Suricata, AWS GuardDuty, Azure Security Center

## 9. Рекомендуемый стек для «Медикаменте»

### Базовый уровень (MVP):
- HashiCorp Vault, ELK Stack, PostgreSQL с шифрованием, Kong API Gateway, Apache Atlas

### Расширенный уровень:
- Azure AD с MFA, Open Policy Agent (OPA), Splunk, Microsoft Purview, Veeam

### Enterprise уровень:
- CyberArk, Symantec DLP, OneTrust, Collibra

## 10. План внедрения

### Фаза 1 (0-3 месяца):
1. Шифрование (Vault, PostgreSQL encryption)
2. Логирование (ELK Stack)
3. Базовый RBAC
4. Тегирование (Apache Atlas)

### Фаза 2 (3-6 месяцев):
1. MFA для всех сотрудников
2. API Gateway с mTLS
3. DLP для внешних интеграций
4. Мониторинг и алертинг

### Фаза 3 (6-12 месяцев):
1. Полный ABAC
2. SIEM с ML-обнаружением
3. Автоматизация compliance
4. Data Lineage для всех потоков
