# Список данных для защиты и методы защиты

## 1. Медицинские карты и диагнозы

**Данные**: Диагнозы, результаты анализов, медицинские заключения, история лечения, назначения

**Методы защиты**:
- Шифрование (Rest): AES-256
- Шифрование (Transit): TLS 1.3
- Обезличивание: Для BI-отчётов, ML-обучения
- Обфускация: Маскирование в логах
- Тегирование: `confidentiality:medical`, `sensitivity:high`

## 2. Персональные данные

**Данные**: ФИО, дата рождения, адрес, телефон, email

**Методы защиты**:
- Шифрование (Rest): AES-256
- Токенизация: Замена на токены в некритичных системах
- Маскирование: Частичное скрытие в интерфейсах
- Хеширование: SHA-256 с солью для поиска дубликатов
- Тегирование: `confidentiality:pii`, `sensitivity:medium`

## 3. Финансовые данные

**Данные**: Платежная информация, суммы оплаты, договоры, бухгалтерские данные

**Методы защиты**:
- Шифрование (Rest): AES-256
- Шифрование (Transit): TLS 1.3
- Сегментация сети: Изоляция в отдельном сегменте
- Тегирование: `confidentiality:financial`, `sensitivity:high`

## 4. Операционные данные

**Данные**: Журналы записей, расписание, история посещений

**Методы защиты**:
- Шифрование (Rest): AES-256
- Обезличивание: Для статистических отчётов
- Тегирование: `confidentiality:operational`, `sensitivity:low`

## 5. Результаты анализов лаборатории

**Данные**: Результаты анализов, реестры, данные для передачи

**Методы защиты**:
- Шифрование (Transit): TLS 1.3, mTLS для API
- Шифрование (Rest): AES-256
- API Security: OAuth 2.0, JWT токены
- DLP: Сканирование передаваемых данных
- Тегирование: `confidentiality:medical`, `sensitivity:high`, `external:laboratory`

## 7. Приоритеты внедрения

### Фаза 1 (Критично - немедленно):
1. Шифрование медицинских карт (Rest + Transit)
2. Шифрование персональных данных (Rest + Transit)
3. Тегирование всех конфиденциальных данных

### Фаза 2 (Высокий - 1-2 месяца):
1. Обезличивание для аналитики
2. Маскирование в интерфейсах
3. DLP для внешних интеграций

### Фаза 3 (Средний - 3-6 месяцев):
1. Токенизация для некритичных систем
2. Расширенная обфускация в логах
3. Хеширование для поиска дубликатов
