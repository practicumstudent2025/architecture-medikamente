# Анализ конфиденциальных данных компании «Медикаменте»

## 1. Выявленные конфиденциальные данные

### 1.1. Персональные данные (PII - Personally Identifiable Information)

#### Базовые персональные данные:
- **ФИО** (Фамилия, Имя, Отчество)
- **Дата рождения**
- **Телефон**
- **Электронная почта**

#### Расширенные персональные данные:
- **Адрес прописки**
- **Место работы или учёбы**
- **Хронические заболевания**
- **Медицинские карты** (содержат диагнозы, результаты анализов, назначения)
- **Результаты анализов** (лабораторные исследования)
- **Медицинские заключения**

### 1.2. Финансовые данные

- **Платежная информация** (данные о платежах, суммы оплаты)
- **Данные договоров** (клиентские контракты)
- **Бухгалтерские данные** (зарплаты, налоги, кадровый учёт)

### 1.3. Операционные данные

- **Журналы записей к специалистам** (расписание, история посещений)
- **Учёт пациентов** (списки пациентов)
- **Учёт оплаты услуг**
- **Товарно-материальные ценности (ТМЦ)**

### 1.4. Данные, не учтённые во внутренних системах

#### Критичные пробелы:
1. **Метаданные доступа** - нет учёта, кто и когда получал доступ к данным
2. **История изменений** - отсутствует аудит изменений в медицинских картах
3. **Логи транзакций** - нет систематического логирования операций с данными
4. **Теги конфиденциальности** - данные не помечены по уровню конфиденциальности
5. **Сроки хранения** - не определены политики хранения и удаления данных
6. **Согласия на обработку** - нет централизованного учёта согласий пациентов
7. **История передачи данных** - не отслеживается передача данных третьим лицам (лабораториям)

## 2. Классификация данных по уровню конфиденциальности

### Уровень 1: Критически конфиденциальные (Красный)
- Медицинские карты с диагнозами
- Результаты анализов
- Хронические заболевания
- Адреса прописки

### Уровень 2: Высококонфиденциальные (Оранжевый)
- ФИО + Дата рождения
- Телефон + Email
- Платежная информация
- Данные договоров

### Уровень 3: Конфиденциальные (Жёлтый)
- Журналы записей (без деталей диагнозов)
- Учёт пациентов (базовые данные)
- Операционные данные

### Уровень 4: Внутренние (Зелёный)
- ТМЦ
- Общая статистика (обезличенная)

## 3. Текущее состояние хранения данных

### 3.1. Форматы хранения
- **Excel файлы** - журналы записей, списки пациентов, реестры анализов
- **JPG/PDF** - сканы медицинских карт, документов
- **1С:Бухгалтерия** - финансовые данные (файловый режим)
- **1С:Торговля и склад** - ТМЦ (файловый режим)
- **Файловый сервер** - общий диск для хранения всех файлов

### 3.2. Проблемы текущего хранения
1. **Отсутствие шифрования** - данные хранятся в открытом виде
2. **Нет контроля доступа** - только доменная аутентификация
3. **Отсутствие аудита** - нет логирования доступа к данным
4. **Ручная обработка** - высокая вероятность ошибок и утечек
5. **Нет резервного копирования** - риск потери данных
6. **Общий доступ** - данные доступны всем сотрудникам в локальной сети
