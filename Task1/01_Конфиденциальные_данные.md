# Анализ конфиденциальных данных компании «Медикаменте»

## 1. Выявленные конфиденциальные данные

### 1.1. Персональные данные (PII)
- **Базовые**: ФИО, дата рождения, телефон, email
- **Расширенные**: адрес прописки, место работы/учёбы, хронические заболевания
- **Медицинские**: медицинские карты, результаты анализов, медицинские заключения

### 1.2. Финансовые данные
- Платежная информация, данные договоров, бухгалтерские данные

### 1.3. Операционные данные
- Журналы записей, учёт пациентов, учёт оплаты услуг, ТМЦ

### 1.4. Данные, не учтённые во внутренних системах
1. Метаданные доступа (кто и когда получал доступ)
2. История изменений (аудит изменений в медицинских картах)
3. Логи транзакций
4. Теги конфиденциальности
5. Сроки хранения (политики хранения и удаления)
6. Согласия на обработку
7. История передачи данных третьим лицам

## 2. Классификация по уровню конфиденциальности

- **Уровень 1 (Красный)**: Медицинские карты, результаты анализов, хронические заболевания, адреса
- **Уровень 2 (Оранжевый)**: ФИО + дата рождения, телефон + email, платежная информация, договоры
- **Уровень 3 (Жёлтый)**: Журналы записей, учёт пациентов, операционные данные
- **Уровень 4 (Зелёный)**: ТМЦ, обезличенная статистика

## 3. Текущее состояние хранения

**Форматы**: Excel, JPG/PDF, 1С:Бухгалтерия, 1С:Торговля и склад, файловый сервер

**Проблемы**:
1. Отсутствие шифрования
2. Нет контроля доступа (только доменная аутентификация)
3. Отсутствие аудита
4. Ручная обработка
5. Нет резервного копирования
6. Общий доступ для всех сотрудников
