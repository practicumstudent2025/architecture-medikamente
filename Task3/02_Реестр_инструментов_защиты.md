# Реестр программных и аппаратных средств для защиты данных

## 1. Инструменты шифрования данных at rest

### 1.1. Управление ключами шифрования

| Инструмент | Назначение | Применение | Статус |
|------------|------------|------------|--------|
| **HashiCorp Vault** | Централизованное управление секретами и ключами | Генерация, хранение, ротация ключей AES-256, управление сертификатами | ✅ Рекомендуется |
| **AWS KMS** | Управление ключами в облаке | Альтернатива для облачных развёртываний | ⚠️ Альтернатива |
| **Azure Key Vault** | Управление ключами в Azure | Для интеграции с Azure AD | ⚠️ Альтернатива |
| **Google Cloud KMS** | Управление ключами в GCP | Для облачных развёртываний | ⚠️ Альтернатива |

### 1.2. Шифрование баз данных

| Инструмент | Назначение | Применение | Статус |
|------------|------------|------------|--------|
| **PostgreSQL TDE (Transparent Data Encryption)** | Шифрование на уровне БД | Медицинские карты, персональные данные | ✅ Рекомендуется |
| **ClickHouse Encryption** | Шифрование Data Lake | Обезличенные данные для аналитики | ✅ Рекомендуется |
| **pgcrypto (PostgreSQL)** | Шифрование на уровне приложения | Дополнительное шифрование критичных полей | ⚠️ Дополнительно |
| **MongoDB Encryption** | Шифрование NoSQL БД | Если используется MongoDB | ⚠️ Альтернатива |

### 1.3. Шифрование файловых хранилищ

| Инструмент | Назначение | Применение | Статус |
|------------|------------|------------|--------|
| **AWS S3 Server-Side Encryption (SSE)** | Шифрование в Object Storage | Файлы, сканы документов | ✅ Рекомендуется |
| **MinIO Encryption** | Шифрование для S3-совместимых хранилищ | On-premise Object Storage | ✅ Рекомендуется |
| **BitLocker (Windows)** | Полнодисковое шифрование | Серверы Windows Server 2022 | ✅ Рекомендуется |
| **LUKS (Linux)** | Полнодисковое шифрование | Linux-серверы | ✅ Рекомендуется |

### 1.4. Шифрование резервных копий

| Инструмент | Назначение | Применение | Статус |
|------------|------------|------------|--------|
| **Veeam Backup Encryption** | Шифрование бэкапов | Резервные копии БД и файлов | ✅ Рекомендуется |
| **BorgBackup** | Шифрованные бэкапы | Альтернатива для Linux | ⚠️ Альтернатива |
| **AWS Backup** | Облачные зашифрованные бэкапы | Для облачных развёртываний | ⚠️ Альтернатива |

## 6. Рекомендуемый стек для «Медикаменте»

### Базовый уровень (MVP - 0-3 месяца)

**Шифрование at rest**:
- HashiCorp Vault (управление ключами)
- PostgreSQL TDE (шифрование БД)
- BitLocker/LUKS (полнодисковое шифрование)
- Veeam Backup Encryption (бэкапы)

**Шифрование in transit**:
- Kong API Gateway (mTLS, OAuth 2.0)
- TLS 1.3 для всех соединений
- Let's Encrypt (публичные сертификаты)
- HashiCorp Vault PKI (внутренние сертификаты)

**Контроль и мониторинг**:
- ELK Stack (логирование и аудит)
- Azure AD (IAM, RBAC, MFA)
- Apache Atlas (тегирование данных)

### Расширенный уровень (3-6 месяцев)

**Дополнительно**:
- Microsoft Purview DLP (предотвращение утечек)
- Open Policy Agent (ABAC политики)
- Prometheus + Grafana (мониторинг)
- Terraform + Ansible (автоматизация)

### Enterprise уровень (6-12 месяцев)

**Дополнительно**:
- Splunk Enterprise Security (SIEM)
- Hardware HSM (для критичных ключей)
- Collibra (Data Governance)
- Расширенный DLP и мониторинг

## 7. План внедрения

### Фаза 1 (0-3 месяца) - Критичные данные
1. HashiCorp Vault для управления ключами
2. PostgreSQL TDE для медицинских карт
3. Kong API Gateway с mTLS для интеграций
4. TLS 1.3 для всех внешних соединений
5. ELK Stack для базового аудита
6. Azure AD с MFA для всех сотрудников

### Фаза 2 (3-6 месяцев) - Расширение защиты
1. Шифрование всех БД (ClickHouse, Elasticsearch)
2. DLP для внешних интеграций
3. Apache Atlas для тегирования
4. Автоматизация через Terraform/Ansible
5. Расширенный мониторинг (Prometheus + Grafana)

### Фаза 3 (6-12 месяцев) - Полная защита
1. Hardware HSM для критичных ключей
2. SIEM с ML-обнаружением аномалий
3. Полный Data Governance (Collibra/Microsoft Purview)
4. Автоматическая ротация ключей
5. Compliance автоматизация
