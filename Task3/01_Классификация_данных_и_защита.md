# Классификация данных и стратегия защиты

## Реестр данных для защиты

| Данные | Состояние | Чувствительность | Профиль риска | В чём необходимость защиты | Инструменты защиты |
|--------|-----------|------------------|---------------|----------------------------|-------------------|
| **Медицинские карты** | Rest, Transit | Критическая | Высокий | 152-ФЗ, врачебная тайна, репутационные риски, штрафы до 18 млн руб. | **Rest**: AES-256 (PostgreSQL TDE, HashiCorp Vault), **Transit**: TLS 1.3, **Контроль**: RBAC/ABAC, Audit logs |
| **Результаты анализов** | Rest, Transit | Критическая | Высокий | 152-ФЗ, врачебная тайна, утечка через API лаборатории | **Rest**: AES-256, **Transit**: mTLS, TLS 1.3, **API**: OAuth 2.0, JWT, **DLP**: Сканирование передаваемых данных |
| **Персональные данные (ФИО, дата рождения, адрес)** | Rest, Transit | Высокая | Высокий | 152-ФЗ, право на неприкосновенность частной жизни, штрафы | **Rest**: AES-256, **Transit**: TLS 1.3, **Маскирование**: В UI для некритичных ролей, **Токенизация**: Для некритичных систем |
| **Контактные данные (телефон, email)** | Rest, Transit | Средняя | Средний | 152-ФЗ, защита от спама, фишинга | **Rest**: AES-256, **Transit**: TLS 1.3, **Маскирование**: Частичное скрытие в интерфейсах |
| **Платежная информация** | Rest, Transit | Критическая | Высокий | PCI DSS, 152-ФЗ, финансовые риски, мошенничество | **Rest**: AES-256, **Transit**: TLS 1.3, **Сегментация**: Изоляция в отдельном сегменте сети, **Токенизация**: Замена реальных данных токенами |
| **Договоры и финансовые документы** | Rest, Transit | Высокая | Средний | Коммерческая тайна, бухгалтерская отчётность | **Rest**: AES-256, **Transit**: TLS 1.3, **Цифровая подпись**: Для документооборота |
| **Журналы записей и расписание** | Rest, Transit | Низкая | Низкий | Операционная конфиденциальность | **Rest**: AES-256, **Transit**: TLS 1.3, **Обезличивание**: Для статистики |
| **Логи и аудит** | Rest, Transit | Средняя | Средний | Соответствие требованиям, расследование инцидентов | **Rest**: AES-256, **Transit**: TLS 1.3, **Целостность**: HMAC, цифровые подписи |
| **Метаданные (теги, политики)** | Rest, Transit | Средняя | Средний | Защита классификации данных | **Rest**: AES-256, **Transit**: TLS 1.3, **Контроль доступа**: Только администраторы |
| **Обезличенные данные для аналитики** | Rest | Низкая | Низкий | Защита от реидентификации | **Rest**: AES-256, **Контроль**: Ограничение доступа к исходным данным |

## Классификация по состоянию данных

### Data at Rest (Данные в покое)

**Определение**: Данные, хранящиеся на дисках, в базах данных, файловых системах, бэкапах.

**Категории**:
- Базы данных (PostgreSQL, ClickHouse)
- Файловые хранилища (Object Storage S3)
- Логи (Elasticsearch)
- Резервные копии
- Архивы

**Риски**:
- Физический доступ к серверам
- Кража/потеря носителей
- Несанкционированный доступ к БД
- Утечка через бэкапы

### Data in Transit (Данные в передаче)

**Определение**: Данные, передаваемые по сети между компонентами системы.

**Категории**:
- API-вызовы (клиент ↔ API Gateway)
- Интеграции (лаборатория, платёжный шлюз)
- Внутренние коммуникации (между сервисами)
- Синхронизация данных
- Загрузка файлов

**Риски**:
- Перехват трафика (Man-in-the-Middle)
- Подмена данных
- Анализ трафика
- Утечка через незащищённые каналы

## Классификация по чувствительности

### Критическая чувствительность
- Медицинские карты
- Результаты анализов
- Платежная информация
- Хронические заболевания

**Требования**: Обязательное шифрование Rest + Transit, строгий контроль доступа, полный аудит.

### Высокая чувствительность
- Персональные данные (ФИО, адрес)
- Договоры
- Финансовые документы

**Требования**: Шифрование Rest + Transit, контроль доступа, аудит критичных операций.

### Средняя чувствительность
- Контактные данные
- Логи и аудит
- Метаданные

**Требования**: Шифрование Rest, TLS для Transit, базовый контроль доступа.

### Низкая чувствительность
- Обезличенные данные
- Операционные данные (статистика)

**Требования**: Базовое шифрование Rest, контроль целостности.

## Профили рисков

### Высокий профиль риска
- **Данные**: Медицинские карты, результаты анализов, платежная информация
- **Угрозы**: Утечка данных, нарушение 152-ФЗ, репутационные риски, финансовые потери
- **Вероятность**: Средняя-высокая
- **Влияние**: Критическое

### Средний профиль риска
- **Данные**: Персональные данные, договоры, логи
- **Угрозы**: Нарушение конфиденциальности, несанкционированный доступ
- **Вероятность**: Средняя
- **Влияние**: Высокое

### Низкий профиль риска
- **Данные**: Обезличенные данные, операционная статистика
- **Угрозы**: Минимальные
- **Вероятность**: Низкая
- **Влияние**: Низкое
